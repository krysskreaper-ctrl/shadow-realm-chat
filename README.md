# shadow-realm-chat
dark chat zombyBomby

## Features

- 👻 Dark theme chat interface with shadow realm aesthetics
- 💬 Real-time text messaging
- 📎 File upload and attachment support
- ⬇️ File download functionality
- 🕒 Message timestamps
- 📦 File size display

## Usage

Simply open `index.html` in your web browser to start chatting!

1. Type messages and press Enter or click Send
2. Click the 📎 button to attach files
3. Click ⬇️ Download to save attached files
